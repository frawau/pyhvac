# hvactest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Textual tool that sends pyhvac's codes to an air conditioner through a Broadlink RM, learns the real remote's codes, and compares them with pyhvac's, field by field.

**Architecture:** `tools/hvactest/` holds five small modules:
- `names` and `log`: persistence;
- `compare`: pure, built on the hvacir matcher;
- `link`: aiobroadlink, the only network code;
- `app`: Textual.

pyhvac's package is untouched, and the tool is not shipped. The hvacir matcher gains a public `candidate(device, name)`, so any single device can be compared.

**Tech Stack:** Python ≥ 3.9 (the tool's tests run on the repo's Python), Textual ≥ 8, aiobroadlink ≥ 0.1.4, pytest. Async tests run through `asyncio.run`, so no pytest-asyncio is needed.

**Spec:** `docs/superpowers/specs/2026-10-10-hvactest-design.md`

**Branch:** `hvacir`.

**Provenance:** every code block below ran in a scratch worktree before the plan was written:
- the tool's tests: 26 passed with Textual installed;
- without Textual, the app tests skip (15 passed, 1 skipped);
- the full suite: 22889 passed, 63 skipped.

## Global Constraints

- The tool is a development tool in `tools/hvactest/`. It is not added to pyhvac's package or dependencies; `textual` and `aiobroadlink` are listed only in `tools/hvactest/requirements.txt`.
- The repo's test suite must pass without Textual or aiobroadlink installed: `tests/test_hvactest_app.py` starts with `pytest.importorskip("textual")`, and no other tool test imports either.
- Metric and UTC only: setpoints are °C as the device offers them; log timestamps are timezone-aware UTC (`datetime.now(timezone.utc)`).
- The session log writes nothing unless `--log FILE` is given.
- Device names live in `~/.pyhvacrc` under the key `"broadlink_names"`:
  - MACs are lower case and colon separated;
  - other keys are kept, and writes are atomic;
  - an unreadable file is reported, and is never written except by a rename.
- `link.py` is the only module that touches the network.
- Run `black` on every Python file you touch.

## Review Focus

   - Expect: "no Broadlink found" is shown; Send and Learn refuse with "no Broadlink selected"; Compare and Match still work on pasted codes.
   - Pinned by `test_no_broadlink_is_reported_and_send_refuses` (Task 5).

   - Pinned by `test_a_learn_timeout_is_reported_and_logged` (Task 5).
3. **A pasted string isn't a Broadlink code.**
   - Expect: an error line; the previous learned code is kept.
   - Pinned by `test_a_pasted_non_code_is_refused` (Task 5).
4. **`~/.pyhvacrc` is malformed.**
   - Expect: reported at startup; names are empty; the file is untouched until a rename.
   - Pinned by `test_a_malformed_file_is_reported_and_left_alone` (Task 2) and `test_a_malformed_rc_file_is_reported` (Task 5).
5. **A learned code no pyhvac model decodes** (an unknown protocol).
   - Expect: "no pyhvac model decodes this code" from Match, and "not this protocol" from Compare.
   - Pinned by `test_match_says_when_no_model_decodes` (Task 5) and `test_another_protocol_is_not_this_protocol` (Task 3).

```python
def candidate(device, name):
    """The Candidate for one Device instance (None if it has no protocol):
    the section sequences and frame lengths it sends, and its parts."""
    if device.PROTOCOL is None:
        return None
    sequences, shapes = set(), set()
    for state in _probe_states(device):
        try:
            frames = device.frames(None, device.normalise(state), ())
        except (TypeError, ValueError, KeyError):
            continue
        sequences.add(tuple(f.section for f in frames))
        shapes.add(tuple(len(f.data) for f in frames))

    # A remote may send part of what pyhvac sends: a message's start (the
    # state without the messages after it) or its tail (a toggle alone).
    def parts(items):
        return {
            tuple(item[i:j])
            for item in list(items)
            for i in range(len(item))
            for j in range(i + 1, len(item) + 1)
            if i == 0 or j == len(item)
        }

    sequences |= parts(sequences)
    shapes |= parts(shapes)
    return Candidate(
        name,
        device,
        tuple(sorted(sequences, key=len)),
        _loose(device.PROTOCOL),
        frozenset(shapes),
    )


def candidates():
    """One Candidate per distinct (Device class, variant) in pyhvac.brands,
    and per variant a class declares in ``VARIANTS`` (one may have no row
    yet: the import is how it gets one)."""
    rows = list(brands.MODELS)
    for brand, model, kind, cls, variant in brands.MODELS:
        rows += [(brand, model, kind, cls, v) for v in getattr(cls, "VARIANTS", ())]
    out, seen = [], set()
    for brand, model, kind, cls, variant in rows:
        if (cls, variant) in seen:
            continue
        seen.add((cls, variant))
        try:
            device = (
                cls(brand, model, variant=variant) if variant else cls(brand, model)
            )
        except (TypeError, ValueError):
            continue
        found = candidate(device, cls.__name__ + (f"/{variant}" if variant else ""))
        if found is not None:
            out.append(found)
    return out
```

`tools/hvactest/names.py`:

```python
"""Names for Broadlink devices, kept in ~/.pyhvacrc.

The file is a JSON object; the names live under "broadlink_names", a map
from MAC address (lower case, colon separated) to name. Other keys are kept
as they are.
"""

import json
import os
from pathlib import Path

DEFAULT_PATH = Path("~/.pyhvacrc").expanduser()
KEY = "broadlink_names"


def _mac(mac):
    return mac.strip().lower().replace("-", ":")


def load(path=DEFAULT_PATH):
    """(names, error): the MAC -> name map and None, or ({}, a message) when
    the file cannot be read or is not a JSON object."""
    path = Path(path)
    if not path.exists():
        return {}, None
    try:
        data = json.loads(path.read_text())
    except (OSError, ValueError) as exc:
        return {}, f"cannot read {path}: {exc}"
    if not isinstance(data, dict) or not isinstance(data.get(KEY, {}), dict):
        return {}, f"{path} is not a JSON object with a {KEY!r} map"
    return {_mac(m): str(n) for m, n in data.get(KEY, {}).items()}, None


def rename(mac, name, path=DEFAULT_PATH):
    """Name the device ``mac`` (an empty name removes it) and write the file
    atomically, keeping its other keys (a file that cannot be read is
    replaced)."""
    path = Path(path)
    try:
        data = json.loads(path.read_text()) if path.exists() else {}
        if not isinstance(data, dict):
            data = {}
    except (OSError, ValueError):
        data = {}
    names = data.get(KEY) if isinstance(data.get(KEY), dict) else {}
    names = {_mac(m): n for m, n in names.items()}
    if name.strip():
        names[_mac(mac)] = name.strip()
    else:
        names.pop(_mac(mac), None)
    data[KEY] = names
    partial = path.with_name(f"{path.name}.{os.getpid()}.tmp")
    partial.write_text(json.dumps(data, indent=2, sort_keys=True) + "\n")
    partial.replace(path)
    return names
```

```python
"""The optional session log: one JSON object per line, UTC timestamps."""

import datetime as dt
import json
from pathlib import Path


class SessionLog:
    """Appends events to ``path``; with ``path=None`` it writes nothing."""

    def __init__(self, path=None):
        self.path = Path(path).expanduser() if path else None

    @property
    def enabled(self):
        return self.path is not None

    def write(self, event, **data):
        if self.path is None:
            return None
        record = {
            "time": dt.datetime.now(dt.timezone.utc).isoformat(),
            "event": event,
            **data,
        }
        with self.path.open("a") as out:
            out.write(json.dumps(record, default=str) + "\n")
        return record
```

```python
"""Compare a learned Broadlink code with what pyhvac sends (no I/O).

Built on the hvacir matcher: the same loose decoding, the same comparison
modulo the fields a capture cannot pin down (the key pressed, toggles, the
remote's clock, checksums).
"""

import base64
import binascii
from dataclasses import dataclass, field
from typing import Dict, Optional, Tuple

from hvacir import match as M
from hvacir.codes import to_pulses
from pyhvac.state import HvacState

NOT_THIS_PROTOCOL = "not this protocol"


@dataclass
class Comparison:
    verdict: str  # "same", "differs" or NOT_THIS_PROTOCOL
    learned: Optional[Tuple[bytes, ...]] = None  # the learned code's frames
    sent: Optional[Tuple[bytes, ...]] = None  # pyhvac's frames for the state
    fields: Dict[str, Tuple[object, object]] = field(default_factory=dict)


@dataclass
class MatchRow:
    name: str  # candidate: "Class" or "Class/variant"
    state: Optional[str]  # a state that sends the code, or None


def packet_pulses(packet):
    """µs pulses of a Broadlink IR packet (bytes)."""
    return to_pulses(base64.b64encode(bytes(packet)).decode(), "Broadlink", "Base64")


def packet_from_base64(text):
    """The packet of a pasted base64 Broadlink code (ValueError if not)."""
    try:
        packet = base64.b64decode(text.strip() + "=" * (-len(text.strip()) % 4))
    except (binascii.Error, ValueError) as exc:
        raise ValueError(f"not base64: {exc}") from None
    packet_pulses(packet)  # raises ValueError if it is no Broadlink IR packet
    return packet


def _values(device, frames):
    """Field name -> value over every layout placed on ``frames`` (a name
    a later frame repeats gets "#<n>")."""
    joined = b"".join(frames)
    lengths = tuple(len(f) for f in frames)
    out = {}
    for offset, layout in M._place(getattr(device, "LAYOUTS", ()), lengths):
        data = joined[offset : offset + len(layout.skeleton)]
        for name, value in layout.read(data).items():
            key, n = name, 1
            while key in out:
                n += 1
                key = f"{name}#{n}"
            out[key] = value
    return out


def _differing(device, learned, sent):
    if tuple(len(f) for f in learned) != tuple(len(f) for f in sent):
        return {"frames": ([len(f) for f in learned], [len(f) for f in sent])}
    got, want = _values(device, learned), _values(device, sent)
    out = {
        name: (got[name], want.get(name))
        for name in got
        if got[name] != want.get(name) and not M.UNRECORDED.match(name.split("#")[0])
    }
    if not out:  # no layout names the bits: show the bytes
        out = {
            f"byte {i}": (f"{a:02x}", f"{b:02x}")
            for i, (a, b) in enumerate(zip(b"".join(learned), b"".join(sent)))
            if a != b
        }
    return out


def compare(device, state, packet, previous=None, name=None):
    """How the learned ``packet`` compares with what ``device`` sends for
    ``state`` (after ``previous``, if given)."""
    cand = M.candidate(device, name or type(device).__name__)
    if cand is None:
        raise ValueError(f"{type(device).__name__} has no IR protocol")
    learned = M.decode_code(cand, packet_pulses(packet))
    if learned is None or not M._valid(device, learned):
        return Comparison(NOT_THIS_PROTOCOL)
    target = device.normalise(state)
    before = None if previous is None else device.normalise(previous)
    sent = tuple(f.data for f in device.frames(before, target, ()))
    seen = M._comparable(device, learned)
    if seen in {M._comparable(device, part) for part in M._parts(sent)}:
        return Comparison("same", learned, sent)
    return Comparison("differs", learned, sent, _differing(device, learned, sent))


def _state_for(cand, frames):
    """A state pyhvac sends ``frames`` for (any mode, setpoint, fan, swing,
    one feature changed; on or off), described, or None."""
    device = cand.device
    seen = M._comparable(device, frames)
    caps = device.capabilities
    defaults = {n: c.values[0] for n, c in caps.features.items()}
    reach = M._reachable(device, [], "C", defaults)
    if seen in reach:
        return M._describe(reach[seen])
    if M._powered_off(device, frames):
        return "off"
    return None


def match_code(packet, cands):
    """Candidates that decode ``packet`` with valid checksums, those with a
    state that sends it first."""
    pulses = packet_pulses(packet)
    rows = []
    for cand in cands:
        frames = M.decode_code(cand, pulses)
        if frames is None or not M._valid(cand.device, frames):
            continue
        rows.append(MatchRow(cand.name, _state_for(cand, frames)))
    return sorted(rows, key=lambda r: (r.state is None, r.name))
```

```python
"""The Broadlink side, through aiobroadlink: the only module that touches
the network."""

import asyncio
import socket
from dataclasses import dataclass

BROADCAST = "255.255.255.255"


@dataclass
class Remote:
    """A Broadlink device that sends and learns IR codes."""

    mac: str
    ip: str
    kind: str  # aiobroadlink's class: rm, rm4, rmp, rm4p
    description: str  # what the device calls itself
    device: object  # the aiobroadlink device


def local_ip(target=BROADCAST):
    """The local address that routes to ``target`` (an arbitrary private
    address for a broadcast)."""
    probe = "10.255.255.255" if target == BROADCAST else target
    with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as sock:
        try:
            sock.connect((probe, 80))
            return sock.getsockname()[0]
        except OSError:
            return "0.0.0.0"


class Link:
    """One aiobroadlink UDP endpoint. ``abl`` (the aiobroadlink module) and
    ``endpoint`` (an async callable making the datagram endpoint) are seams
    the tests replace."""

    def __init__(self, abl=None, endpoint=None):
        if abl is None:
            from aiobroadlink import aiobroadlink as abl
        self.abl = abl
        self._endpoint = endpoint
        self.protocol = None
        self.bind_ip = None

    async def start(self, target=BROADCAST):
        self.protocol = self.abl.BroadlinkProtocol()
        self.bind_ip = local_ip(target)
        if self._endpoint is not None:
            await self._endpoint(self.protocol, self.bind_ip)
        else:
            loop = asyncio.get_running_loop()
            await loop.create_datagram_endpoint(
                lambda: self.protocol, local_addr=(self.bind_ip, 0)
            )

    async def discover(self, target=BROADCAST, timeout=5.0):
        """The IR-capable devices answering a Hello (broadcast, or unicast
        to ``target``) within ``timeout`` seconds."""
        scout = self.abl.BroadlinkDevice(0x1234, "Scout")
        scout.controller = self.protocol
        scout.ip = target
        _, port = self.protocol.transport.get_extra_info("sockname")[:2]
        scout.hello(self.bind_ip, port)
        found = {}
        loop = asyncio.get_running_loop()
        end = loop.time() + timeout
        while (left := end - loop.time()) > 0:
            try:
                dev = await asyncio.wait_for(scout.result.get(), timeout=left)
            except asyncio.TimeoutError:
                break
            if not isinstance(dev, self.abl.rm):
                continue  # plugs, sensors: no IR
            self.protocol.register(dev)
            found[dev.mac] = Remote(dev.mac, dev.ip, type(dev).__name__, dev.name, dev)
        return sorted(found.values(), key=lambda r: r.ip)

    async def send(self, remote, packet, timeout=5):
        """Whether ``remote`` acknowledged sending the IR ``packet``."""
        return bool(await remote.device.send_code(bytes(packet), timeout=timeout))

    async def learn(self, remote, timeout=10):
        """The packet ``remote`` learned within ``timeout`` seconds, or None."""
        code = await remote.device.learn_ir_code(timeout=timeout)
        return bytes(code) if code else None

    def close(self):
        if self.protocol is not None and self.protocol.transport is not None:
            self.protocol.transport.close()
```

```python
            features[name] = q(f"#feature-{name}").value
        return HvacState(
            q("#power", Switch).value,
            q("#mode", Select).value,
            q("#setpoint", Select).value,
            features=features,
            **kw,
        )

    def describe(self, state):
        on = [n for n, v in state.features.items() if v]
        text = (
            f"{'on' if state.power else 'off'} {state.mode} {state.temperature:g}°C "
            f"fan {state.fan} swing {state.swing_v}/{state.swing_h}"
        )
        return text + "".join(f" +{n}" for n in on)

    # ------------------------------------------------------------- actions
    def ready(self, need_remote=True):
        if self.device is None:
            self.say("[yellow]choose a brand and model first[/]")
            return False
        if need_remote and (self.link is None or self.remote() is None):
            self.say("[yellow]no Broadlink selected[/]")
            return False
        return True

    @on(Button.Pressed, "#send")
    def on_send(self):
        if self.ready():
            self.send()

    @work(exclusive=True, group="link")
    async def send(self):
        state = self.state()
        try:
            command = self.device.encode(self.previous, state)
        except (ValueError, KeyError) as exc:
            self.say(f"[red]cannot encode: {exc}[/]")
            return
        packet = to_broadlink(command.signal)
        remote = self.remote()
        ok = await self.link.send(remote, packet)
        if ok:
            self.previous = command.state
        self.say(
            f"sent {self.describe(command.state)}: "
            + (
                "[green]acknowledged[/]"
                if ok
                else f"[red]no answer from {self.label(remote)}[/]"
            )
        )
        self.log_.write(
            "send",
            model=list(self.model),
            state=self.describe(command.state),
            code=b64(packet),
            acknowledged=ok,
        )

    @on(Button.Pressed, "#learn")
    def on_learn(self):
        if self.ready(need_remote=True):
            self.learn()

    @work(exclusive=True, group="link")
    async def learn(self):
        self.say("press the button on the real remote (10 s)…")
        packet = await self.link.learn(self.remote())
        if packet is None:
            self.say("[yellow]nothing learned within 10 s[/]")
            self.log_.write("learn", model=list(self.model), code=None)
            return
        self.learned = packet
        self.log_.write("learn", model=list(self.model), code=b64(packet))
        self.show_compare()

    @on(Input.Submitted, "#paste")
    def on_paste(self, event):
        try:
            self.learned = packet_from_base64(event.value)
        except ValueError as exc:
            self.say(f"[red]{exc}[/]")
            return
        self.log_.write("paste", code=b64(self.learned))
        if self.device is not None:
            self.show_compare()
        else:
            self.say("code read; choose a model to compare, or Match")

    @on(Button.Pressed, "#compare")
    def on_compare(self):
        if self.learned is None:
            self.say("[yellow]learn or paste a code first[/]")
        elif self.ready(need_remote=False):
            self.show_compare()

    def show_compare(self):
        state = self.state()
        result = compare(self.device, state, self.learned, self.previous)
        self.say(f"compare with {self.describe(state)}: [b]{result.verdict}[/]")
        if result.verdict == "differs":
            table = Table("field", "learned", "pyhvac")
            for name, (got, want) in result.fields.items():
                table.add_row(name, str(got), str(want))
            self.say(table)
        elif result.verdict == "not this protocol":
            self.say("try Match to find the model that sends it")
        self.log_.write(
            "compare",
            model=list(self.model),
            state=self.describe(state),
            verdict=result.verdict,
            fields={k: list(map(str, v)) for k, v in result.fields.items()},
        )

    @on(Button.Pressed, "#match")
    def on_match(self):
        if self.learned is None:
            self.say("[yellow]learn or paste a code first[/]")
        else:
            self.match()

    @work(exclusive=True, group="match", thread=True)
    def match(self):
        if self.candidates is None:
            self.call_from_thread(self.say, "loading every pyhvac model…")
            self.candidates = M.candidates()
        rows = match_code(self.learned, self.candidates)
        self.call_from_thread(self.show_match, rows)

    def show_match(self, rows):
        if not rows:
            self.say("[yellow]no pyhvac model decodes this code[/]")
        else:
            table = Table("model", "state that sends it")
            for row in rows[:15]:
                table.add_row(row.name, row.state or "(decodes; no state matches)")
            self.say(table)
        self.log_.write("match", rows=[[r.name, r.state] for r in rows])

    @on(Button.Pressed, "#log")
    def on_log(self):
        verdict = self.query_one("#verdict", Select).value
        if verdict is Select.BLANK:
            self.say("[yellow]choose a verdict[/]")
            return
        note = self.query_one("#note", Input).value
        record = self.log_.write(
            "verdict",
            model=list(self.model) if self.model else None,
            state=self.describe(self.previous) if self.previous else None,
            verdict=verdict,
            note=note,
        )
        self.say(f"verdict: {verdict}" + ("" if record else " (logging is off)"))

    def on_unmount(self):
        if self.link is not None:
            self.link.close()
```
